❓ Frequently Asked Questions (FAQ)

Is JanSetu free to use for all citizens?

Yes! JanSetu is a 100% free public civic bridge. We do not charge any fee for accessing government links, tracking scheme status, or using built-in utility tools.

Is my personal data safe when using the Photo Resizer or Resume Builder?

Yes, completely. All image compression and document generation happen 100% locally inside your phone/computer browser memory. Nothing is stored or uploaded to any central server.

Can I register GST or file returns without hiring a CA?

Yes. The Indian tax system allows self-assessment. Anyone with an Aadhaar-linked mobile number can register a new GSTIN and file monthly GSTR-1/GSTR-3B returns directly using free Aadhaar OTP verification.
